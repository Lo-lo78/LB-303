LB-303: user guide

Version 0.99.1 · 27 October 2026

Continuous Length 101 ties

Length 101 is a real tie: consecutive steps with the same pitch keep one uninterrupted note, even from step 16 back to step 1 in a looping pattern. With a different pitch, the sequencer performs a legato hand-off. The first ordinary Length ends the phrase after its own gate; Pause breaks it.

Overview

LB-303 is an accessible dual-bassline synthesizer with two independent monophonic engines, 16 patterns of up to 128 steps per bassline, two-channel Song editor, step Parameter Locks, separate distortion inserts and shared effects. It works as a VST3 in REAPER and supports keyboard navigation and screen readers.

Main interface and keyboard

The main interface uses Grid, Value and Edit. Tab moves Grid → Value → Edit; Shift+Tab moves backwards. Alt+L focuses Grid, Alt+V focuses Value and Alt+E starts numeric Edit. Enter switches between Grid and Value or accepts an edited value. Ctrl+Tab cycles Bassline 1, Bassline 2, Sequencer and FX. Grid arrow keys select parameters; type a letter or number to search parameter names. Alt+Up/Down changes a value, Alt+Page Up/Down changes it by a larger increment, Alt+Home sets its maximum, Alt+End its minimum, and Backspace resets the selected parameter. Alt+Left/Right changes the editing step. Ctrl+Up/Down selects the current bassline pattern (1–16).

Sound generation and accent

Each bassline has oscillators, resonant filter, envelopes and LFO modulation. The basslines can use different MIDI channels and patterns. Accent comes from step velocity and the existing Accent Threshold and accent parameters: there is no separate Accent On/Off step page. On the sequencer Velocity page change the velocity to shape the accent. Length 101 enables Legato for that step.

Step editor: Alt+Q

Alt+Q opens the step editor. Keys 1–7 select the pages Note, Length, Velocity, Repeat, Shift, Launch Step and Parameters. Q–I and A–K select the 16 steps in the visible block; Tab/Shift+Tab changes blocks within the active Start/End range. Home/End switches basslines; Ctrl+Up/Down changes pattern. Z/X adjusts Start Step and C/V adjusts End Step. Up/Down changes the value by one; Page Up/Page Down uses the increment selected with Left/Right. Alt+I reads the current step information.

Enter and step selection

On Note, Enter alternates Pause and the actual previous note of each step (for example 72 → Pause → 72). On Length, Enter alternates 101 Legato and the actual previous length (37 → 101 → 37). On Velocity, Enter alternates the maximum velocity 127 with that step’s last user-selected velocity (for example 85 → 127 → 85), providing quick accents without a separate Accent toggle. Each step remembers its own value in saved patterns. On Parameters, Enter opens the parameter picker. Ctrl+A selects the visible 16 steps; Delete clears the step selection without erasing notes. Ctrl+C/Ctrl+X/Ctrl+V copies, cuts and pastes selected steps. Ctrl+Z and Ctrl+Shift+Z are Undo and Redo. Ctrl+Shift+C/X/V operates on the entire current pattern only.

Parameter Locks and Song

On page 7 Parameters, Enter opens the synthesis parameter list. Navigate with arrows; Enter assigns a parameter and returns to the step editor, while Alt+Enter changes the assignment without leaving the list. Up/Down edits the selected lock. Delete removes the selected lock when no steps are selected. Alt+Delete removes all locks from the current step. Alt+S inside Alt+Q switches between Steps and Song editor. The Song editor offers two independent bassline lanes with ordered pattern entries and looping. Alt+M switches Pattern/Song preview mode.

Preview and transport

Alt+P switches what Space controls: DAW (default, leaving transport to REAPER) or Sequencer preview. In Preview mode, Space starts or stops both basslines together. Esc or Alt+Q closes the step editor without stopping an already running preview. Returning Alt+P to DAW mode stops the preview. Alt+I outside the step editor initializes the plugin; inside the step editor it reads status.

Preset browser

Alt+B opens the browser; Alt+S opens Save preset. Alt++ / Alt+- selects the next or previous stored preset. Presets are .lb files under Documents\LB-303 on Windows. Up/Down, Home/End and Page Up/Page Down browse; the highlighted preset can be previewed. Enter on a preset CONFIRMS loading, while Enter on a folder enters it. Escape, Alt+C or Alt+B cancels without adopting an unconfirmed preview. Opening the browser again selects the last CONFIRMED loaded preset, even in a new instance or after restarting REAPER. Merely navigating or previewing does not change that remembered position. F2 renames, Ctrl+N creates a folder and Delete requests removal confirmation.

Effects and oversampling

The FX context contains per-bassline Distortion 1 and Distortion 2, plus shared Chorus, Delay and Reverb. The parameter Oversampling Basslines and Distortions selects 1×, 2× or 4×. The original 1× path is the default. Oversampling applies to the bassline engines and their individual distortions; shared effects remain at the host sample rate. Switching quality during a sounding note may create a small discontinuity. The DSP can sleep when silent to reduce idle CPU. Additional stereo output buses are available for individual basslines and wet FX.

Help and About

Alt+H opens the Help language menu and opens this guide in your default web browser. Use the language links above to switch versions. Alt+A opens About. About displays version 0.99.1, release date 27 October 2026, the AGPL-3.0-or-later license, project address and contact email. Within About, use arrow keys to read the text, Tab/Shift+Tab for Project, Contact and Close, Enter to activate the focused control, and Escape or Alt+C to close it.

LB-303: guida per l’utente

Version 0.99.1 · 27 October 2026

Legato 101 continuo

Length 101 lega davvero gli step: quelli con la stessa nota producono una sola nota continua, anche dallo step 16 al primo nel pattern in loop. Se cambia altezza, il passaggio è legato senza interruzione del gate. Il primo step con Length normale conclude la frase secondo la propria durata; Pause la interrompe.

Panoramica

LB-303 è un sintetizzatore accessibile con due bassline monofoniche indipendenti, 16 pattern fino a 128 step per bassline, un editor Song a due colonne, Parameter Locks per step, due distorsori separati ed effetti condivisi. Funziona come VST3 in REAPER e supporta tastiera e lettori di schermo.

Interfaccia principale e tastiera

L’interfaccia usa Grid, Value ed Edit. Tab passa da Grid a Value a Edit; Shift+Tab procede all’indietro. Alt+L porta a Grid, Alt+V a Value e Alt+E apre la modifica numerica. Invio passa fra Grid e Value o conferma il numero inserito. Ctrl+Tab cambia contesto fra Bassline 1, Bassline 2, Sequencer e FX. Le frecce nella Grid selezionano i parametri; lettere e numeri ne cercano il nome. Alt+Su/Giù modifica il valore, Alt+Pagina su/giù lo cambia con un passo maggiore, Alt+Home imposta il massimo, Alt+End il minimo e Backspace ripristina il parametro. Alt+Sinistra/Destra cambia il passo di modifica. Ctrl+Su/Giù sceglie il pattern della bassline, da 1 a 16.

Sintesi e Accent

Ciascuna bassline dispone di oscillatori, filtro risonante, inviluppi e modulazione LFO. Le bassline possono usare canali MIDI e pattern differenti. L’Accent dipende dalla velocity dello step e dagli attuali parametri di accentuazione, tra cui Accent Threshold: non esiste una pagina Accent On/Off separata. Regola la pagina Velocity per variare l’accento. Length 101 attiva il Legato dello step.

Editor degli step: Alt+Q

Alt+Q apre il sequencer. I tasti da 1 a 7 scelgono Note, Length, Velocity, Repeat, Shift, Launch Step e Parameters. Q–I e A–K selezionano i 16 step del blocco visibile; Tab e Shift+Tab cambiano blocco nei limiti Start/End. Home/End cambia bassline; Ctrl+Su/Giù cambia pattern. Z/X modifica Start Step e C/V modifica End Step. Su/Giù modifica di una unità; Pagina su/giù usa il passo scelto con Sinistra/Destra. Alt+I legge lo stato corrente.

Invio e selezione degli step

Nella pagina Note, Invio alterna fra Pausa e la vera nota precedente dello step, per esempio 72 → Pausa → 72. In Length, Invio alterna fra 101 Legato e la vera lunghezza precedente, per esempio 37 → 101 → 37. Nella pagina Velocity, Invio alterna fra il massimo 127 e l’ultima velocity scelta dall’utente su quello step (per esempio 85 → 127 → 85), per creare accenti senza una pagina Accent separata. Ogni step ricorda il proprio valore anche nei pattern salvati. In Parameters, Invio apre la scelta dei parametri. Ctrl+A seleziona i 16 step visibili; Delete deseleziona senza cancellare le note. Ctrl+C/X/V copia, taglia e incolla gli step selezionati. Ctrl+Z e Ctrl+Shift+Z annullano e ripristinano. Ctrl+Shift+C/X/V agisce invece soltanto sull’intero pattern corrente.

Parameter Locks e Song

Nella pagina 7 Parameters, Invio apre la lista dei parametri di sintesi. Le frecce navigano; Invio assegna un parametro e torna agli step, mentre Alt+Invio modifica l’assegnazione senza uscire dall’elenco. Su/Giù modifica il lock selezionato. Delete elimina il lock corrente quando non ci sono step selezionati; Alt+Delete elimina tutti i lock dello step. Alt+S dentro Alt+Q passa da Steps all’editor Song. Song gestisce due colonne indipendenti di pattern ordinati con ripetizione. Alt+M commuta l’anteprima fra Pattern e Song.

Anteprima e trasporto

Alt+P alterna il comportamento di Spazio fra DAW (predefinito, lasciato a REAPER) e Sequencer preview. In Preview, Spazio avvia o ferma entrambe le bassline insieme. Esc oppure Alt+Q chiude l’editor senza arrestare l’anteprima già avviata. Tornando con Alt+P alla modalità DAW l’anteprima si ferma. Alt+I, fuori dall’editor degli step, inizializza il plugin; dentro l’editor legge lo stato.

Browser dei preset

Alt+B apre il browser; Alt+S apre Salva preset. Alt++ e Alt+- caricano il preset successivo o precedente. Su Windows i file .lb sono in Documenti\LB-303. Su/Giù, Home/End e Pagina su/giù esplorano l’elenco; la selezione consente l’anteprima. Invio su un preset ne CONFERMA il caricamento; Invio su una cartella la apre. Esc, Alt+C o Alt+B annulla senza conservare l’anteprima non confermata. Alla riapertura, anche in una nuova istanza o dopo il riavvio di REAPER, il browser torna all’ultimo preset CARICATO con conferma. Il semplice spostamento o ascolto in anteprima non cambia la memoria. F2 rinomina; Ctrl+N crea una cartella; Delete chiede conferma prima di eliminare.

Effetti e oversampling

La pagina FX include Distortion 1 e Distortion 2, separati per bassline, oltre a Chorus, Delay e Reverb condivisi. Il parametro Oversampling Basslines and Distortions offre 1×, 2× e 4×. La modalità originale 1× è predefinita. L’oversampling interessa i motori delle bassline e i rispettivi distorsori; gli effetti condivisi lavorano alla frequenza del progetto. Cambiare qualità durante una nota può produrre una piccola discontinuità. Il DSP può entrare a riposo durante il silenzio per ridurre l’Idle. Sono disponibili anche uscite stereo separate per le bassline e per il solo segnale wet.

Alt+A apre About: mostra versione 0.99.1, data 27 October 2026, licenza AGPL-3.0-or-later, progetto e contatto. In About usa le frecce per leggere il testo, Tab/Shift+Tab per Project, Contact e Close, Invio per attivare il controllo ed Esc oppure Alt+C per chiudere.

LB-303: guía de usuario

Version 0.99.1 · 27 October 2026

Legato 101 continuo

Length 101 enlaza los pasos: varias notas iguales siguen sonando sin interrupción, incluso del paso 16 al 1 cuando el patrón se repite. Si cambia la altura, se produce una transición ligada. El primer Length normal termina la frase según su duración; Pause la interrumpe.

Descripción general

LB-303 es un sintetizador accesible con dos líneas de bajo monofónicas independientes, 16 patrones de hasta 128 pasos por línea, editor Song de dos pistas, bloqueos de parámetros por paso, dos distorsiones independientes y efectos compartidos. Funciona como VST3 en REAPER y se controla con teclado y lector de pantalla.

Interfaz principal

La interfaz contiene Grid, Value y Edit. Tab recorre Grid → Value → Edit y Mayús+Tab vuelve atrás. Alt+L lleva a Grid, Alt+V a Value y Alt+E a la edición numérica. Intro cambia entre Grid y Value o confirma el valor escrito. Ctrl+Tab alterna Bassline 1, Bassline 2, Sequencer y FX. Las flechas recorren los parámetros y las letras y números buscan nombres. Alt+Arriba/Abajo cambia el valor; Alt+RePág/AvPág lo cambia más; Alt+Inicio lo pone al máximo, Alt+Fin al mínimo y Retroceso restaura el parámetro. Alt+Izquierda/Derecha modifica el incremento. Ctrl+Arriba/Abajo elige el patrón 1–16.

Síntesis y Accent

Cada línea de bajo tiene osciladores, filtro resonante, envolventes y LFO. Las dos líneas pueden utilizar canales MIDI y patrones distintos. Accent depende de la velocidad del paso y de los parámetros existentes, incluido Accent Threshold; no hay una página adicional Accent On/Off. La página Velocity ajusta la acentuación y Length 101 activa Legato.

Editor de pasos Alt+Q

Alt+Q abre el editor. Las teclas 1–7 eligen Note, Length, Velocity, Repeat, Shift, Launch Step y Parameters. Q–I y A–K eligen los 16 pasos visibles. Tab/Mayús+Tab cambia de bloque dentro del rango Start/End. Inicio/Fin cambia de línea de bajo; Ctrl+Arriba/Abajo cambia de patrón. Z/X modifica Start Step y C/V modifica End Step. Arriba/Abajo cambia una unidad; RePág/AvPág usa el incremento elegido con Izquierda/Derecha. Alt+I anuncia el estado.

Intro y selección

En Note, Intro alterna Pausa y la última nota real del paso: 72 → Pausa → 72. En Length alterna 101 Legato y la duración anterior: 37 → 101 → 37. En Velocity, Intro alterna entre el máximo 127 y la última velocidad elegida para ese paso (por ejemplo, 85 → 127 → 85), facilitando los acentos sin una página Accent adicional. Cada paso recuerda su valor al guardar. En Parameters, Intro abre la lista de parámetros. Ctrl+A selecciona los 16 pasos visibles y Supr deselecciona sin borrar notas. Ctrl+C/X/V copia, corta y pega pasos; Ctrl+Z y Ctrl+Mayús+Z deshace y rehace. Ctrl+Mayús+C/X/V actúa solo sobre el patrón completo actual.

Bloqueos de parámetros y Song

En la página 7, Intro abre el selector de parámetros. Las flechas navegan, Intro asigna y regresa, Alt+Intro asigna sin cerrar. Arriba/Abajo modifica el bloqueo. Supr elimina el bloqueo actual cuando no hay pasos seleccionados; Alt+Supr borra todos los bloqueos del paso. Alt+S dentro de Alt+Q alterna Steps y Song. Song ofrece dos pistas independientes de patrones ordenados y repetición. Alt+M alterna vista previa Pattern/Song.

Vista previa y transporte

Alt+P cambia la función de Espacio entre DAW (predeterminado, transporte de REAPER) y Sequencer preview. En Preview, Espacio inicia o detiene ambas líneas. Esc o Alt+Q cierra el editor sin parar la reproducción previa. Volver a DAW con Alt+P detiene la vista previa. Fuera del editor Alt+I inicializa el instrumento; dentro anuncia el estado.

Explorador de presets

Alt+B abre el explorador y Alt+S guarda. Alt++/Alt+- carga el preset siguiente o anterior. Los archivos .lb están en Documentos\LB-303 (Windows). Las flechas, Inicio/Fin y RePág/AvPág recorren la lista y permiten oír una vista previa. Intro sobre un preset CONFIRMA la carga; sobre una carpeta entra en ella. Esc, Alt+C o Alt+B cancela la vista previa no confirmada. El explorador vuelve siempre al último preset cargado y confirmado, incluso en nuevas instancias o tras reiniciar REAPER. Navegar o escuchar no altera esa memoria. F2 renombra, Ctrl+N crea una carpeta y Supr solicita confirmación para eliminar.

Efectos y sobremuestreo

FX incluye Distortion 1 y 2 independientes y Chorus, Delay y Reverb compartidos. Oversampling Basslines and Distortions ofrece 1×, 2× y 4×, con 1× como valor original predeterminado. Los motores y sus distorsiones funcionan con sobremuestreo; los efectos compartidos siguen a la frecuencia del proyecto. Cambiarlo durante una nota puede causar un pequeño clic. El DSP entra en reposo durante el silencio para reducir CPU y existen salidas estéreo independientes.

Ayuda y About

Alt+A abre About con versión 0.99.1, fecha 27 October 2026, licencia AGPL-3.0-or-later, proyecto y contacto. En About, las flechas leen texto, Tab/Mayús+Tab recorre Project, Contact y Close, Intro activa y Esc o Alt+C cierra.

LB-303 : guide utilisateur

Version 0.99.1 · 27 October 2026

Legato 101 continu

Length 101 lie les pas : plusieurs notes identiques restent tenues sans interruption, y compris du pas 16 au premier lors de la boucle. Un changement de hauteur produit une transition legato. Le premier Length normal termine la phrase selon sa durée ; Pause l’interrompt.

Présentation

LB-303 est un synthétiseur accessible à deux basslines monophoniques indépendantes, avec 16 patterns de 128 pas maximum par bassline, un éditeur Song à deux pistes, des Parameter Locks par pas, deux distorsions distinctes et des effets partagés. Il fonctionne comme VST3 dans REAPER, au clavier et avec un lecteur d’écran.

Interface et raccourcis

L’interface comporte Grid, Value et Edit. Tab parcourt Grid → Value → Edit ; Maj+Tab revient en arrière. Alt+L rejoint Grid, Alt+V Value et Alt+E la saisie numérique. Entrée bascule entre Grid et Value ou valide une saisie. Ctrl+Tab parcourt Bassline 1, Bassline 2, Sequencer et FX. Les flèches sélectionnent les paramètres et les touches alphanumériques cherchent leurs noms. Alt+Haut/Bas modifie la valeur, Alt+Page précédente/suivante utilise un pas plus grand, Alt+Début fixe le maximum, Alt+Fin le minimum, et Retour arrière réinitialise. Alt+Gauche/Droite modifie le pas. Ctrl+Haut/Bas choisit le pattern 1–16.

Synthèse et Accent

Chaque bassline comprend oscillateurs, filtre résonant, enveloppes et LFO. Les canaux MIDI et les patterns sont indépendants. Accent est déterminé par la vélocité et les paramètres existants, notamment Accent Threshold : il n’existe pas de page Accent On/Off séparée. La page Velocity règle l’accentuation ; Length 101 active Legato.

Éditeur de pas Alt+Q

Alt+Q ouvre l’éditeur. Les touches 1–7 choisissent Note, Length, Velocity, Repeat, Shift, Launch Step et Parameters. Q–I et A–K sélectionnent les 16 pas affichés ; Tab/Maj+Tab change de bloc dans l’intervalle Start/End. Début/Fin change de bassline ; Ctrl+Haut/Bas change de pattern. Z/X modifie Start Step et C/V End Step. Haut/Bas modifie d’une unité ; Page précédente/suivante utilise le pas choisi avec Gauche/Droite. Alt+I annonce les informations.

Entrée et sélection

Sur Note, Entrée alterne Pause et la dernière note réelle de chaque pas : 72 → Pause → 72. Sur Length, elle alterne 101 Legato et la longueur précédente : 37 → 101 → 37. Sur Velocity, Entrée alterne entre le maximum 127 et la dernière vélocité choisie pour chaque pas (par exemple 85 → 127 → 85), pour créer des accents sans page Accent supplémentaire. Chaque pas conserve sa valeur à l’enregistrement. Sur Parameters, Entrée ouvre le sélecteur. Ctrl+A sélectionne les 16 pas visibles ; Suppr efface la sélection sans modifier les notes. Ctrl+C/X/V copie, coupe et colle les pas. Ctrl+Z et Ctrl+Maj+Z annulent et rétablissent. Ctrl+Maj+C/X/V concerne le pattern complet courant.

Parameter Locks et Song

Sur la page 7, Entrée ouvre la liste des paramètres. Les flèches naviguent ; Entrée affecte un paramètre puis revient aux pas, Alt+Entrée l’affecte sans fermer. Haut/Bas modifie le lock courant. Suppr efface le lock lorsqu’aucun pas n’est sélectionné ; Alt+Suppr efface tous les locks du pas. Alt+S dans Alt+Q alterne Steps et Song. Song propose deux pistes indépendantes de patterns ordonnés, avec répétition. Alt+M choisit l’aperçu Pattern ou Song.

Aperçu et transport

Alt+P définit la touche Espace : DAW (par défaut, transport REAPER) ou Sequencer preview. En Preview, Espace lance ou arrête les deux basslines. Échap ou Alt+Q ferme l’éditeur sans interrompre l’aperçu déjà lancé. Revenir au mode DAW avec Alt+P arrête l’aperçu. Alt+I initialise le plugin hors de l’éditeur ; dans l’éditeur, il lit l’état.

Navigateur de presets

Alt+B ouvre le navigateur et Alt+S la sauvegarde. Alt++/Alt+- charge le preset précédent ou suivant. Les fichiers .lb résident dans Documents\LB-303 sous Windows. Flèches, Début/Fin et Page précédente/suivante permettent de parcourir et préécouter. Entrée sur un preset CONFIRME le chargement ; sur un dossier, elle l’ouvre. Échap, Alt+C ou Alt+B annule la préécoute non confirmée. Le navigateur se replace sur le dernier preset effectivement confirmé, même avec une nouvelle instance ou après redémarrage de REAPER. Parcourir et écouter ne modifie pas cette mémoire. F2 renomme, Ctrl+N crée un dossier et Suppr demande confirmation avant suppression.

Effets et suréchantillonnage

La page FX propose Distortion 1 et 2 par bassline et Chorus, Delay et Reverb partagés. Oversampling Basslines and Distortions sélectionne 1×, 2× ou 4× ; 1× est le mode original par défaut. La synthèse et les distorsions sont suréchantillonnées ; les effets partagés restent à la fréquence du projet. Changer le facteur pendant une note peut produire une légère discontinuité. Le DSP se met en veille pendant le silence afin de réduire le CPU ; des sorties stéréo distinctes sont disponibles.

LB-303: руководство пользователя

Version 0.99.1 · 27 October 2026

Непрерывное Legato 101

Length 101 связывает шаги: одинаковые ноты звучат непрерывно, в том числе при переходе от 16-го шага к первому в цикле. При смене высоты переход происходит legato. Первый шаг с обычным Length завершает фразу по своей длительности; Pause прерывает её.

Обзор

LB-303 — доступный синтезатор с двумя независимыми монофоническими басовыми партиями. Для каждой доступны 16 паттернов по 128 шагов, редактор Song с двумя дорожками, блокировки параметров на шагах, собственный дисторшн и общие эффекты. Плагин VST3 работает в REAPER с клавиатурой и программами экранного доступа.

Основной интерфейс

Три основных элемента: Grid, Value и Edit. Tab переключает Grid → Value → Edit, Shift+Tab — назад. Alt+L открывает Grid, Alt+V — Value, Alt+E — числовое редактирование. Enter переключает Grid и Value либо подтверждает ввод. Ctrl+Tab выбирает Bassline 1, Bassline 2, Sequencer и FX. Стрелки перемещают по параметрам, буквы и цифры ищут по названию. Alt+Вверх/Вниз меняет значение, Alt+Page Up/Down — крупным шагом, Alt+Home — максимум, Alt+End — минимум, Backspace — сброс. Alt+Влево/Вправо меняет шаг редактирования. Ctrl+Вверх/Вниз выбирает паттерн 1–16.

Синтез и Accent

Каждая басовая партия имеет осцилляторы, резонансный фильтр, огибающие и LFO. MIDI-каналы и паттерны независимы. Accent зависит от velocity шага и существующих настроек, включая Accent Threshold. Отдельной страницы Accent On/Off нет. Меняйте Velocity для акцентирования; Length 101 включает Legato.

Редактор шагов Alt+Q

Alt+Q открывает редактор. Клавиши 1–7 выбирают Note, Length, Velocity, Repeat, Shift, Launch Step, Parameters. Q–I и A–K выбирают 16 видимых шагов. Tab/Shift+Tab переключает блоки в пределах Start/End. Home/End меняет басовую партию, Ctrl+Вверх/Вниз — паттерн. Z/X меняет Start Step, C/V — End Step. Вверх/Вниз меняет значение на единицу, Page Up/Down — на величину, выбранную Влево/Вправо. Alt+I сообщает состояние.

Enter и выделение

На странице Note Enter переключает паузу и предыдущую ноту конкретного шага: 72 → Pause → 72. На Length переключает 101 Legato и предыдущую длительность: 37 → 101 → 37. На странице Velocity клавиша Enter переключает максимальное значение 127 и последнее установленное пользователем значение для этого шага (например 85 → 127 → 85). Это позволяет быстро добавлять акценты без отдельной страницы Accent. У каждого шага своя сохраняемая память. На Parameters Enter открывает список параметров. Ctrl+A выделяет 16 видимых шагов, Delete снимает выделение без удаления нот. Ctrl+C/X/V копирует, вырезает и вставляет шаги; Ctrl+Z и Ctrl+Shift+Z отменяет и повторяет действие. Ctrl+Shift+C/X/V обрабатывает только текущий паттерн целиком.

Parameter Locks и Song

На странице 7 Enter открывает список параметров. Стрелки перемещают, Enter назначает параметр и возвращается, Alt+Enter назначает без закрытия. Вверх/Вниз меняет значение блокировки. Delete удаляет текущую блокировку, если нет выделенных шагов; Alt+Delete удаляет все блокировки шага. Alt+S внутри Alt+Q переключает Steps и Song. В Song две независимые дорожки с последовательностями паттернов и повторениями. Alt+M переключает предпрослушивание Pattern/Song.

Прослушивание

Alt+P переключает действие пробела: DAW (по умолчанию транспорт REAPER) или Sequencer preview. В режиме Preview пробел запускает и останавливает обе басовые партии. Esc или Alt+Q закрывает редактор, не останавливая уже идущее прослушивание. Возврат в DAW через Alt+P останавливает его. Вне редактора Alt+I инициализирует плагин, внутри — читает состояние.

Браузер пресетов

Alt+B открывает браузер, Alt+S — сохранение. Alt++/Alt+- загружает следующий или предыдущий пресет. Файлы .lb находятся в Документы\LB-303 (Windows). Стрелки, Home/End и Page Up/Down позволяют перемещаться и прослушивать. Enter на пресете ПОДТВЕРЖДАЕТ загрузку, на папке открывает её. Esc, Alt+C или Alt+B отменяет неподтверждённое прослушивание. При следующем открытии выбирается последний подтверждённый пресет даже в новом экземпляре и после перезапуска REAPER. Простое перемещение или прослушивание память не меняет. F2 переименовывает, Ctrl+N создаёт папку, Delete запрашивает подтверждение удаления.

Эффекты и oversampling

Раздел FX содержит Distortion 1 и 2 отдельно для басовых партий, общий Chorus, Delay и Reverb. Oversampling Basslines and Distortions выбирает 1×, 2× или 4×; исходный режим 1× используется по умолчанию. Синтез и дисторшн работают с повышенной частотой, общие эффекты — на частоте проекта. Изменение режима во время звучания может вызвать щелчок. В тишине DSP переходит в режим экономии CPU; доступны отдельные стереовыходы.

Help и About

Alt+H открывает меню языков и руководство в браузере по умолчанию. Ссылки вверху переключают язык. Alt+A открывает About с версией 0.99.1, датой 27 October 2026, лицензией AGPL-3.0-or-later, адресом проекта и контактом. В About стрелки читают текст, Tab/Shift+Tab выбирает Project, Contact, Close, Enter активирует, Esc или Alt+C закрывает.

LB-303 用户指南

Version 0.99.1 · 27 October 2026

连续 Legato 101

Length 101 会连接相邻步进：相同音高持续发声，循环时从第 16 步回到第 1 步也不会中断。音高变化时进行连奏过渡。遇到普通 Length 时，按该步长度结束乐句；Pause 会中断。

概述

LB-303 是支持键盘和屏幕阅读器的双低音合成器，包含两个独立的单音声部。每个声部有 16 个 Pattern，每个最多 128 步；还提供双轨 Song 编辑器、逐步 Parameter Locks、两个独立失真以及共享效果。插件以 VST3 形式在 REAPER 中使用。

主界面和快捷键

主界面包括 Grid、Value 和 Edit。Tab 依次切换 Grid → Value → Edit，Shift+Tab 反向。Alt+L 定位 Grid，Alt+V 定位 Value，Alt+E 打开数字编辑。Enter 在 Grid/Value 间切换或确认输入。Ctrl+Tab 切换 Bassline 1、Bassline 2、Sequencer、FX。方向键选择参数，字母和数字按名称搜索。Alt+上/下调整值；Alt+Page Up/Down 大幅调整；Alt+Home 设为最大，Alt+End 设为最小，Backspace 重置。Alt+左/右更改编辑步幅；Ctrl+上/下选择 Pattern 1–16。

音色与 Accent

每条 Bassline 包含振荡器、共振滤波器、包络与 LFO；可以使用不同 MIDI 通道和 Pattern。Accent 由步的 Velocity 以及现有的 Accent Threshold 等参数控制，没有单独的 Accent On/Off 页面。通过 Velocity 页面调节重音；Length 101 表示 Legato。

Alt+Q 步进编辑器

Alt+Q 打开编辑器。数字 1–7 分别选择 Note、Length、Velocity、Repeat、Shift、Launch Step、Parameters。Q–I 和 A–K 对应当前可见的 16 步，Tab/Shift+Tab 在 Start/End 范围内切换区块。Home/End 切换 Bassline，Ctrl+上/下切换 Pattern。Z/X 修改 Start Step，C/V 修改 End Step。上/下每次修改 1，Page Up/Down 按左/右设置的较大步幅修改。Alt+I 朗读当前状态。

Enter 与选中步骤

在 Note 页面，Enter 在 Pause 和该步上次实际音高之间切换，例如 72 → Pause → 72。在 Length 页面，Enter 在 101 Legato 和上次长度之间切换，例如 37 → 101 → 37。在 Velocity 页面，Enter 在最大力度 127 和该步上次由用户设置的力度之间切换，例如 85 → 127 → 85，可快速制作重音而无需单独的 Accent 页面。每一步独立记忆并随 Pattern 保存。在 Parameters 页面，Enter 打开参数列表。Ctrl+A 选中当前 16 步，Delete 仅清除选择而不删除音符。Ctrl+C/X/V 复制、剪切、粘贴步骤；Ctrl+Z、Ctrl+Shift+Z 撤销和重做；Ctrl+Shift+C/X/V 处理整个当前 Pattern。

Parameter Locks 与 Song

第 7 页 Parameters 中，Enter 打开参数选择器。方向键导航；Enter 分配参数并返回，Alt+Enter 分配而不关闭。上/下修改当前锁定值。没有选中步骤时，Delete 删除当前锁定；Alt+Delete 删除当前步骤的所有锁定。Alt+Q 内按 Alt+S 在 Steps 与 Song 间切换。Song 支持两条独立的 Pattern 顺序及重复。Alt+M 切换 Pattern/Song 试听。

试听与传输

Alt+P 选择空格键控制 DAW（默认，交给 REAPER）或 Sequencer preview。在 Preview 模式下，空格同时开始或停止两个 Bassline。Esc 或 Alt+Q 关闭编辑器，但不会停止已经运行的试听。使用 Alt+P 返回 DAW 时试听停止。编辑器外的 Alt+I 初始化插件；编辑器内用于朗读状态。

预设浏览器

Alt+B 打开预设浏览器，Alt+S 保存预设。Alt++/Alt+- 加载前一个或后一个预设。Windows 中 .lb 文件位于 Documents\LB-303。方向键、Home/End、Page Up/Down 浏览并试听。对预设按 Enter 才会确认加载；对文件夹按 Enter 会进入文件夹。Esc、Alt+C 或 Alt+B 取消未确认的试听。再次打开浏览器时，无论是否新建实例或重启 REAPER，都定位到最后确认加载的预设。仅浏览或试听不会改变记录。F2 重命名，Ctrl+N 新建文件夹，Delete 删除前要求确认。

效果与过采样

FX 页面提供独立的 Distortion 1、Distortion 2，以及共享的 Chorus、Delay、Reverb。Oversampling Basslines and Distortions 可选 1×、2×、4×，默认原始模式 1×。合成与各自失真进行过采样，而共享效果仍以工程采样率运行。音符播放时切换可能出现小的跳变。静音时 DSP 会休眠以降低 CPU 占用；还提供单独的立体声输出。

Help 与 About

Alt+H 选择语言，并在默认浏览器打开此指南；顶部链接可切换语言。Alt+A 打开 About，其中包含版本 0.99.1、发布日期 27 October 2026、AGPL-3.0-or-later 许可证、项目链接和联系邮箱。在 About 中，方向键阅读文本，Tab/Shift+Tab 移动到 Project、Contact、Close，Enter 激活，Esc 或 Alt+C 关闭。

LB-303 ユーザーガイド

Version 0.99.1 · 27 October 2026

連続する Legato 101

Length 101 はステップをつなぐタイです。同じ音高が続く間は発音を切らず、ループ時の16ステップ目から1ステップ目にもつながります。音高が変わる場合はレガートで移行します。通常の Length を持つ最初のステップの長さでフレーズが終わり、Pause で途切れます。

概要

LB-303 はスクリーンリーダーとキーボードで操作できる、独立した2つのモノフォニック・ベースラインを持つシンセサイザーです。各ベースラインには最大128ステップの16パターン、2トラックの Song エディター、ステップごとの Parameter Locks、独立したディストーション、共有エフェクトがあります。REAPER で VST3 として動作します。

メイン画面と操作

メイン画面には Grid、Value、Edit があります。Tab は Grid → Value → Edit の順、Shift+Tab は逆順です。Alt+L は Grid、Alt+V は Value、Alt+E は数値入力に移動します。Enter は Grid/Value の切り替えか入力確定です。Ctrl+Tab は Bassline 1、Bassline 2、Sequencer、FX を切り替えます。矢印キーでパラメーターを選択し、英数字で名前を検索できます。Alt+上/下で値を変更、Alt+Page Up/Down で大きく変更、Alt+Home は最大、Alt+End は最小、Backspace は初期化です。Alt+左/右で編集幅を変更します。Ctrl+上/下はパターン1〜16を選びます。

音源と Accent

各ベースラインにはオシレーター、レゾナントフィルター、エンベロープ、LFO があり、MIDI チャンネルとパターンを別々に設定できます。Accent はステップの Velocity と Accent Threshold などの既存パラメーターで制御します。独立した Accent On/Off ページはありません。Velocity でアクセントを調節し、Length 101 で Legato を有効にします。

Alt+Q ステップエディター

Alt+Q で開きます。数字1〜7は Note、Length、Velocity、Repeat、Shift、Launch Step、Parameters です。Q〜I と A〜K で表示中の16ステップを選択します。Tab/Shift+Tab は Start/End の範囲内で16ステップのブロックを移動します。Home/End は Bassline を切り替え、Ctrl+上/下はパターンを切り替えます。Z/X は Start Step、C/V は End Step を変更します。上/下は1単位、Page Up/Down は左/右で設定した編集幅で変更します。Alt+I は現在の状態を読み上げます。

Enter とステップ選択

Note ページの Enter は Pause とそのステップの直前の音高を交互に切り替えます（72 → Pause → 72）。Length の Enter は 101 Legato と以前の長さを切り替えます（37 → 101 → 37）。Velocity ページの Enter は最大値127とそのステップで最後に設定したベロシティを切り替えます（例：85 → 127 → 85）。独立した Accent ページなしでアクセントを付けられます。値はステップごとに保存されます。Parameters では Enter がパラメーター選択画面を開きます。Ctrl+A は表示中の16ステップを選択し、Delete はノートを消さずに選択だけを解除します。Ctrl+C/X/V はステップのコピー・切り取り・貼り付け、Ctrl+Z と Ctrl+Shift+Z は Undo/Redo です。Ctrl+Shift+C/X/V は現在のパターン全体に作用します。

Parameter Locks と Song

ページ7の Parameters では Enter でパラメーター一覧を開きます。矢印で選択、Enter で追加して戻り、Alt+Enter で一覧を閉じずに変更します。上/下でロック値を編集します。ステップが選択されていないとき Delete は選択中のロックを削除し、Alt+Delete はそのステップの全ロックを削除します。Alt+Q 内の Alt+S で Steps/Song を切り替えます。Song は2つの独立したパターン列と繰り返しに対応します。Alt+M は Pattern/Song プレビューを切り替えます。

プレビューと再生

Alt+P は Space の役割を DAW（初期値、REAPER のトランスポート）または Sequencer preview に切り替えます。Preview では Space で2つのベースラインを同時に再生・停止します。Esc または Alt+Q でエディターを閉じても、すでに動作しているプレビューは止まりません。Alt+P で DAW に戻すと停止します。エディター外の Alt+I はプラグインを初期化し、エディター内では状態を読み上げます。

プリセットブラウザー

Alt+B はブラウザー、Alt+S は保存です。Alt++/Alt+- は前後のプリセットをロードします。Windows の .lb ファイルは Documents\LB-303 にあります。矢印、Home/End、Page Up/Down で移動・試聴します。プリセットで Enter を押したときだけロードが確定します。フォルダーの Enter はそのフォルダーを開きます。Esc、Alt+C、Alt+B は未確定の試聴を取り消します。次回ブラウザーを開くと、新しいインスタンスや REAPER 再起動後でも最後に確定ロードしたプリセットが選択されます。移動や試聴だけでは記憶は変わりません。F2 は名前変更、Ctrl+N はフォルダー作成、Delete は確認後に削除します。

エフェクトとオーバーサンプリング

FX には独立した Distortion 1/2 と、共有の Chorus、Delay、Reverb があります。Oversampling Basslines and Distortions は 1×、2×、4× を選択でき、初期値は従来の 1× です。シンセと各ディストーションを高いサンプルレートで処理し、共有エフェクトはプロジェクトのサンプルレートのままです。発音中の切り替えで小さなノイズが出る場合があります。無音時は DSP が休止して CPU 使用量を抑え、独立したステレオ出力も利用できます。
